Load Spend File

Two years of supplier spend. Any IT category — cloud, software, telecom, hardware, services.

Nothing you load here leaves this machine. The file is parsed in your browser. This page makes no network requests with your data, writes nothing to browser storage, and forgets everything on reload — you can disconnect from the network and it will still work, which is the simplest way to demonstrate that to a client. Supplier names are the one thing that cannot be dropped, since they are what the analysis keys on, so treat the loaded view as client-confidential and use Export anonymised summary in stage 4 for anything you intend to share or store.
