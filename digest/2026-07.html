Cloud Negotiation
Research Digest

Issue 01 · July 22, 2026

Where the three hyperscalers moved this period, what practitioners are reporting, and what it changes about how we advise a renewal.

What's New

5 items
  • Azure

    Azure EA-to-MCA-E migration is accelerating

    From March 1, 2026, Microsoft began moving EA customers on MACC plans to MCA-E ahead of renewal. Clients on EA Levels B/C/D are losing automatic discounts with no equivalent in MCA-E. — SoftwareOne →

  • GCP

    GCP CUD scope changed June 16, 2026

    New billing accounts now default to billing-account-level CUD sharing. Existing accounts with active commitments are unchanged, but project-level chargeback setups are now at risk. — usage.ai →

  • GCP

    Flex CUDs now cover GKE Autopilot and Cloud Run

    A single Flex CUD can now cover the entire compute footprint — VMs, GKE, and Cloud Run — reducing the need for separate commitments per service. — Google Cloud blog →

  • AWS

    AWS Database Savings Plans now GA

    Launched December 2025, covering Aurora Serverless, DocumentDB, Neptune, Keyspaces, and Timestream with 12–35% discounts on 1-year no-upfront terms. Underutilized in most EDP negotiations. — ProsperOps →

  • Industry

    FinOps X 2026 — negotiation becomes a formal capability

    The State of FinOps report (1,192 practitioners, $83B cloud spend) confirms FinOps teams are now expected to lead provider negotiations. C-suite sponsorship correlates with 2–4x higher negotiation influence. — FinOps Foundation →

AWS

EDP structure is unchanged, but practitioners continue to report that AWS's first EDP offer leaves 15–25% of total contract value on the table. Key lever: AWS Marketplace ISV spend now counts toward EDP drawdown (up to 25% of commitment), which is a significant new negotiation angle for clients with $500K+ in Marketplace purchases.

Additionally, Database Savings Plans are largely absent from EDP negotiations — flagging these proactively creates a fresh discount workstream. Credits (migration, ProServ, Marketplace) remain almost universally excluded from initial offers.

Sources Redress — AWS EDP Negotiation Guide 2026 · ProsperOps — FinOps X 2026 Announcements · The Negotiation Experts — EDP Guide

Azure

The EA-to-MCA-E migration is the dominant story. Clients moving without negotiation are seeing 10–30% cost increases — EA Levels B/C/D eliminated, no default price lock in MCA-E, and the evergreen structure removes renewal leverage.

The strongest tactic right now: separate Azure MACC commitments from M365, put Azure into a CSP relationship where partner economics favor the client, and treat every renewal as a clean-sheet negotiation. Microsoft Copilot and MACC are the two levers that move the 2026 deal band most.

Sources SoftwareOne — EA to MCA-E · Redress — EA Negotiation Strategies 2026 · MicrosoftNegotiations.com — EA Playbook 2025–2026 · SAMexpert — Is EA Still Worth It in 2026?

Google Cloud

Two significant changes in H1 2026. First, the January 2026 spend-based CUD billing model shift (multiprice/direct discount, not credit offset) changes how savings appear in billing reports — clients need to update chargeback calculations. Second, the June 16 CUD scope default change to billing-account level is disrupting project-level chargeback setups.

For enterprise clients with a CASC (Customer Annual Spend Commitment), an additional 3–7 percentage points of CUD discount can be negotiated outside the public sleeve — this is underutilized.

Sources usage.ai — GCP June 2026 Updates · North Cloud — Multiprice CUD Guide · VendorBenchmark — GCP Pricing Benchmarks 2026 · usage.ai — Resource vs Flex CUDs 2026

Community & Practitioner Pulse

5 items
  • Industry

    FinOps X 2026 — negotiation as a core capability

    Practitioners with C-suite sponsorship are 2–4x more likely to influence cloud vendor selection. Negotiation is now a formal FinOps capability, not a side task. — Flexera → FinOps Framework →

  • AWS

    Database Savings Plans are being left on the table

    Fewer than half of organizations use any commitment discount type with any cloud provider. Database Savings Plans are newly available and almost entirely missing from EDP negotiations. — ProsperOps → Explainer →

  • Timing

    Start earlier — a recurring practitioner theme

    AWS EDP should begin 6–9 months before expiry; Azure EA 9–12 months out. Waiting for the vendor's 60–90 day reminder hands all negotiating leverage to the provider. — Negotiation Experts → Redress →

  • Azure

    M365 shelfware inflates the pricing baseline

    Practitioners report 7–19% of M365 licenses are unused in estates that have never run a reclamation pass. Reclaiming before renewal is an underutilized lever that reduces the baseline Microsoft uses to set pricing. — MicrosoftNegotiations.com →

  • AI Pricing

    AI pricing is a new negotiation frontier

    Copilot, Vertex AI, and Bedrock usage-based pricing should be treated as infrastructure procurement, not software licensing. FinOps teams are the right internal counterpart for these deals. — Atonement Licensing → FinOps Foundation →

Sourcing Note

Several figures in this issue come from secondary commentary rather than provider documentation. The 10–30% MCA-E migration cost increase, the 15–25% of contract value left on the table in a first EDP offer, and the additional 3–7pp CUD discount negotiable outside the public sleeve all originate with advisory firms and practitioner blogs. They are directionally consistent with what we see in market, but they are not vendor-published figures. Confirm against Microsoft, AWS, and Google primary documentation before citing any of them to a client.
Retroactive source warning — added August 20, 2026. One source cited in the GCP section above, vendorbenchmark.com, subsequently failed verification: it publishes Salesforce Enterprise list price as $330 per user per month, which is in fact the Unlimited rate, and discloses no sample size, time period, or methodology. Treat the GCP pricing-benchmark reference drawn from it as unverified, and do not cite the domain in future issues. The other GCP sources in that section are unaffected.
